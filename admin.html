ບັນຊີນີ້ເປັນ "ຜູ້ສຳພາດ"

ບັນຊີ ບໍ່ມີສິດເຂົ້າແຜງຄວບຄຸມ — ເບິ່ງໃບສະໝັກໄດ້ທີ່ໜ້າຜູ້ສຳພາດ (ອ່ານຢ່າງດຽວ)

ໄປໜ້າຜູ້ສຳພາດ

ຜູ້ໃຊ້ແມ່ນ:

ແຜງຄວບຄຸມ

ແທັບນີ້ຄື ຄັງຕຳແໜ່ງຂອງທັງອົງກອນ — ໃສ່ໄວ້ວ່າອົງກອນມີຕຳແໜ່ງໃດແດ່ (ຊື່ ປະເພດ ພາລະໜ້າທີ່) ໂດຍຍັງບໍ່ຕ້ອງລະບຸວ່າສາຂາໃດຮັບ — ການເປີດຮັບ ແລະ ຈຳນວນອັດຕາ ໃຫ້ໄປຕັ້ງເອົາຢູ່ແທັບ "ຈັດການສາຂາ" ໃຜສາຂາມັນ

ແຕ່ລະສາຂາເລືອກເອງວ່າ ມີຕຳແໜ່ງໃດແດ່ ຈາກຄັງຕຳແໜ່ງ (ແທັບ "ຈັດການພະແນກ") ແລ້ວໃສ່ຈຳນວນອັດຕາ:
• ຈຳນວນ = 0 → ສາຂາມີຕຳແໜ່ງນີ້ ແຕ່ຍັງບໍ່ເປີດຮັບ (ຂຶ້ນໄວ້ໃຫ້ຄົນສົນໃຈ "ຝາກປະຫວັດ")
• ຈຳນວນ ≥ 1 → ເປີດຮັບຈຳນວນອັດຕານັ້ນ ແລະ ຈະຂຶ້ນປ້າຍສີຂຽວຢູ່ໜ້າເວັບ
• ຕຳແໜ່ງທີ່ບໍ່ໄດ້ເພີ່ມໄວ້ → ຈະບໍ່ສະແດງໃນສາຂານັ້ນເລີຍ

ບັນຊີຜູ້ໃຊ້ງານລະບົບ

ກຳນົດວ່າໃຜເປັນ ຜູ້ດູແລລະບົບ (ແກ້ໄຂໄດ້ທຸກຢ່າງ) ແລະ ໃຜເປັນ ຜູ້ສຳພາດ (ເບິ່ງໃບສະໝັກຢ່າງດຽວ ຜ່ານ interview.html)
ຂັ້ນຕອນ: ສ້າງບັນຊີກ່ອນທີ່ Firebase Console → Authentication → Add user ແລ້ວກັອບປີ້ User UID ມາໃສ່ດ້ານລຸ່ມ
⚠️ ບັນຊີທີ່ຍັງບໍ່ຢູ່ໃນລາຍການນີ້ ຈະຖືວ່າເປັນຜູ້ດູແລລະບົບໂດຍອັດຕະໂນມັດ

 

ຫົວຂໍ້ໃຫ້ຄະແນນຕອນສຳພາດ

ຫົວຂໍ້ເຫຼົ່ານີ້ຈະໄປສະແດງໃນໜ້າຜູ້ສຳພາດ (interview.html) ໃຫ້ຄະແນນ 0–5 ຕໍ່ຫົວຂໍ້ ພ້ອມກ່ອງຄຳເຫັນຂອງແຕ່ລະຫົວຂໍ້
ເພີ່ມ / ລຶບ / ຈັດລຳດັບໄດ້ຕາມຕ້ອງການ — ແນະນຳ 4–6 ຫົວຂໍ້
⚠️ ຖ້າລຶບຫົວຂໍ້ທີ່ໃຫ້ຄະແນນໄປແລ້ວ ຄະແນນເກົ່າຂອງຫົວຂໍ້ນັ້ນຈະບໍ່ຖືກນຳມາຄິດອີກ

ອີເມວທີ່ແຈ້ງເຕືອນເວລາມີໃບສະໝັກໃໝ່

ເມື່ອມີຄົນສົ່ງໃບສະໝັກ ລະບົບຈະສົ່ງອີເມວແຈ້ງໄປຫາທີ່ຢູ່ເຫຼົ່ານີ້ (1 ແຖວ = 1 ອີເມວ) — ຕ້ອງຕິດຕັ້ງ Extension "Trigger Email from Firestore" ກ່ອນ ອີເມວຈຶ່ງຈະຖືກສົ່ງແທ້ (ເບິ່ງ README)

ຊ່ອງກອກໃນຟອມສະໝັກງານ

ຟອມສະໝັກງານທັງໝົດຖືກສ້າງຈາກລາຍການລຸ່ມນີ້ — ເພີ່ມ / ລຶບ / ຈັດລຳດັບ / ປ່ຽນຊື່ 2 ພາສາ ໄດ້ໝົດ ໂດຍບໍ່ຕ້ອງແກ້ໂຄດ (ເຊັ່ນ ຢາກເພີ່ມ "ຊື່-ນາມສະກຸນ ພາສາອັງກິດ" ກໍ່ກົດ "+ ເພີ່ມຊ່ອງກອກ" ໄດ້ເລີຍ)
• ຮອງຮັບ: ຂໍ້ຄວາມ / ຂໍ້ຄວາມຍາວ / ຕົວເລືອກ / ອີເມວ / ເບີໂທ / ຕົວເລກ / ວັນທີ / ລິງ / ແນບ PDF / ແນບຮູບ
• ຊ່ອງລະບົບ 3 ຊ່ອງ (ຊື່, ອີເມວ, ເບີໂທລະສັບ) ລຶບບໍ່ໄດ້ ແລະ ບັງຄັບກອກສະເໝີ ແຕ່ປ່ຽນຊື່ປ້າຍ ຈັດລຳດັບ ແລະ ປັບຄວາມກວ້າງໄດ້ຕາມປົກກະຕິ
• ຢ່າລືມກົດ "ບັນທຶກຟອມ" ທຸກຄັ້ງ ຟອມໜ້າເວັບຈຶ່ງຈະປ່ຽນຕາມ

ຖ້າທຸກຊ່ອງຢູ່ "ໜ້າທີ 1" ໝົດ ຟອມຈະເປັນໜ້າດຽວຄືເກົ່າ — ຖ້າຢາກແບ່ງເປັນຫຼາຍໜ້າ ໃຫ້ຕັ້ງຄ່າ "ຢູ່ໜ້າທີ (ຂັ້ນຕອນ)" ຂອງແຕ່ລະຊ່ອງ ແລ້ວຜູ້ສະໝັກຈະເຫັນປຸ່ມ "ຖັດໄປ →"
